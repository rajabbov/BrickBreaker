# BrickBreaker

A complete brick-breaker arcade game — 9x10 brick grid, touch-controlled paddle and animated ball physics — written without a game engine.

## Features

- Ball movement and collision handled with `ValueAnimator`
- Paddle follows touch drag along the bottom of the screen
- 90 destructible bricks with live score tracking
- Win and game-over states

## Tech stack

- **Language:** Kotlin
- **UI:** XML layouts with View binding
- **SDK:** min 24, target 34
- **Package:** `com.example.brickbreaker`

## Getting started

```bash
git clone https://github.com/rajabbov/BrickBreaker.git
```

Open the folder in Android Studio, let Gradle sync, and run the `app` configuration on a device or emulator.
